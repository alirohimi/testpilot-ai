AI-powered pytest plugin for intelligent test failure triage, scrubbing, and classification.

## 🎯 What is TestPilot AI?

TestPilot AI is a pytest plugin that uses AI to:
- **Triage** test failures intelligently
- **Scrub** sensitive data from test outputs
- **Classify** failures by type and severity
- **Generate** actionable fix suggestions

## 🚀 Quick Start

```bash
pip install testpilot-ai
pytest --testpilot
```

## ✨ Features

- 🤖 **AI-Powered Triage**: Automatically categorizes test failures
- 🔒 **Privacy Scrubbing**: Removes sensitive data from test outputs
- 📊 **Failure Classification**: Groups similar failures together
- 💡 **Fix Suggestions**: Provides actionable remediation steps
- ⚡ **Zero Config**: Works out of the box with pytest
