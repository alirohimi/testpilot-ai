API Reference

Complete REST API documentation for TestPilot AI.

Base URL: https://api.testpilot.ai (or your self-hosted endpoint)

All endpoints require either Authorization: Bearer <token> or X-API-Key: <key>

Auth

Register

POST /api/v1/auth/register
Content-Type: application/json

{
  "email": "user@example.com",
  "password": "strongpassword",
  "full_name": "Jane Doe"
}

Response: 201 Created — { "access_token", "token_type", "user": {...} }

Login

POST /api/v1/auth/login
Content-Type: application/json

{ "email": "user@example.com", "password": "..." }

API Keys

MethodEndpointDescription
GET/api/v1/auth/keysList keys
POST/api/v1/auth/keysCreate key
DELETE/api/v1/auth/keys/{id}Revoke key

Triage

MethodEndpointDescription
POST/api/v1/triage/classifyClassify a single failure
POST/api/v1/triage/runFull triage pipeline
GET/api/v1/triage/resultsGet results

Scrub

POST /api/v1/scrub
Body: { "text": "<test output>" }

Usage

GET /api/v1/usage/summary       — Credits used, plan info

Health

GET /api/v1/health
