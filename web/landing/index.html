Features

Everything you need to stop
debugging failures manually

Three core capabilities. Zero configuration. Works with your existing test suite.

🔍

Intelligent Classification

Classify test failures by root cause — infrastructure, assertion, environment, timing — using LLM-powered analysis with fuzzy matching and pattern library.

🚦

AI-Powered Triage

Auto-prioritize failures by business impact, team ownership, and historical recurrence. Get human-readable suggestions, not raw stack traces.

🧹

PII Scrubbing

Automatically detect and redact emails, API keys, credit cards, tokens, and custom patterns from test output before it reaches your CI or Allure reports.

🔗

Allure & Slack Integration

Inject triage results directly into Allure reports. Send failure alerts to Slack with categorized insights. Plugin handles both.

🧬

Mutation Testing

Generate mutant tests to validate your test suite's fault-detection capability. Know exactly which failures your tests can and can't catch.

📊

Pattern Library & History

Build a searchable knowledge base of historical failures. Find similar issues across sprints and get category recommendations.

How It Works

Three commands. Zero friction.

01

Install & Configure

pip install testpilot-ai-plugin[pytest] and add --triage to your pytest config. Takes 2 minutes.

02

Run Tests

Every failure is automatically classified, triaged, and scrubbed. Results go to your local triage directory.

03

Review & Ship

Check triage/results.json or see results in Allure. Slack gets notified. You ship with confidence.
